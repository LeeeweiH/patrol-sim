# 前端说明

原生 HTML + CSS + JavaScript 实现的二维巡检仿真控制台。没有框架、没有构建工具、没有第三方 CDN 依赖，静态文件由 FastAPI 直接托管在根路径。

## 功能与环境

- 已实现的页面和操作：8×8 地图查看（障碍物、机器人位置与朝向）、四方向手动控制（按钮点击或键盘方向键）、状态反馈（坐标／朝向／运行状态、连接徽标、中文错误提示、重新读取状态）。
- 巡检痕迹：走过的格子会留下淡蓝色底与一个圆点，侧栏实时显示本次会话的「步数」与「经过」格数；机器人每次移动有 200ms 的滑动过渡（`prefers-reduced-motion: reduce` 时自动关闭）。
- 前端使用原生 HTML + CSS + JavaScript（ES2017+，无框架、无打包）开发，地图用 CSS Grid 绘制，每个格子同时用颜色和「障」「机」文字标注，避免只靠颜色区分。
- 本地运行需要安装现代浏览器（Edge / Chrome / Firefox 的较新版本）即可；前端本身不需要安装任何依赖，也不需要 Node.js。联调需要 Python 3.10+ 运行后端（见 [后端说明](../backend/README.md)）。

## 本地启动流程

1. **进入目录。** 从仓库根目录进入 `backend/`。
2. **安装依赖。** 执行 `pip install -r requirements.txt`。
3. **配置后端地址。** 前端不含硬编码地址，页面和接口同源；`app.js` 内所有请求都写成相对路径 `/api/state`、`/api/move`，由浏览器按当前页面地址自动补全，因此无需配置。
4. **启动后端（前端不单独启动）。** 在 `backend/` 下执行 `python -m uvicorn app.main:app --reload`，然后在浏览器打开 `http://localhost:8080/`。`app/main.py` 已经把仓库的 `frontend/` 目录挂载到根路径，所以不需要另起静态服务器。
5. **验证页面和联调。** 页面上应看到 8×8 网格、机器人位于 `(0, 0)`、朝向 `上 ↑`。点击「向右」按钮，坐标变为 `(1, 0)`。在开发者工具的网络面板里能看到 `GET /api/state` 与 `POST /api/move`，预期状态码均为 `200`；越界或撞障碍时 `POST /api/move` 返回 `409`，页面给出中文提示且位置不变。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架：顶栏与连接徽标、地图容器、状态面板、四个方向按钮、重新读取按钮、键盘操作提示 |
| `styles.css` | 主题变量与地图网格样式，含窄屏适配（格子从 56px 缩到 40px）、焦点描边、禁用态、减少动效偏好 |
| `app.js` | 请求封装与交互逻辑，见下 |

`app.js` 的关键函数：

- `requestJSON(path, options)`：统一请求封装，8 秒超时（`AbortController`），检查 `response.ok`，解析 JSON，失败时抛出带 `code` 的 `ApiError`。
- `validateState(data)`：校验后端返回的网格尺寸、障碍物坐标、机器人坐标与朝向，结构不符直接报错，不把半截数据画到页面上。
- `renderState(state)`：按后端状态整体重建地图与状态面板；`state` 之外还接收 `{ moved, from }`，用来把「上一格 → 新格」的位移交给 CSS 做滑动动画。
- `trackPosition(state, previous)`：记录行走轨迹与步数。正常移动累加一格；若位置跳变超过一格（别的标签页移动过、重新读取时已不同步），清空轨迹重新计数，避免画出错误路线。
- `loadState()` / `move(direction)`：`GET /api/state` 与 `POST /api/move`，请求期间禁用按钮（`busy`），避免并发。
- `syncControls()`：统一控制按钮禁用状态与 `aria-busy`。

## 交互与错误处理约定

- 前端不预测位置：移动成功与否、移动到哪一格，一律以后端返回的完整状态为准。
- 后端明确拒绝（`400` / `409`，如越界、撞障碍）时，提示「移动被拒绝：…」，画面保持上一次确认过的状态。
- 超时、网络异常、`5xx` 或响应格式不符时，视为「结果未确认」，页面提示点击「重新读取状态」，不会自动重发请求。
- 连接状态徽标会随请求结果切换为「服务在线／未连接服务」。

## 构建与检查

- 构建：不适用（纯静态文件，无打包、无产物目录）。
- 依赖安装：不适用（前端不引入任何第三方包）。
- 提交前的人工检查：
  1. 浏览器控制台无报错；
  2. 窗口缩到 375px 宽时地图不横向溢出；
  3. 用 `Tab` 键能依次聚焦到四个方向按钮与「重新读取状态」，回车可触发；
  4. 停掉后端再点方向按钮，应出现中文错误提示而不是页面卡死。
