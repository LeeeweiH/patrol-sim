# 使用指南（前端）

面向第一次打开页面的同学：怎么看图、怎么操作、出错怎么办。技术细节和接口契约见 [03_项目架构与接口.md](./03_项目架构与接口.md)。

## 一、界面上都有什么

页面分左右两块：左边是地图（占满左侧，格子约 100 像素），右边是控制面板和状态。右栏左边有个 `›` 标签，点一下可以把右栏收起来、地图再放大一圈；收起后标签变成 `‹`，再点一下恢复。

| 标记 | 含义 |
| --- | --- |
| 浅色格子 | 可通行区域 |
| 淡蓝格子 + 小圆点 | 这次打开页面后走过的格子（巡检痕迹） |
| 红色牌子「禁止通行」 | 障碍物，不能进入，也站不了人 |
| 机器狗立牌 + 橙色地灯光锥 | 机器人当前位置，脚下那道光锥指向当前朝向 |
| 左上角红色门 / 右下角蓝色门 | 起点与终点标记，可以踩上去，不挡路 |
| 最上面一行的 0–7 | 列坐标 x，向右递增 |
| 最左一列的 0–7 | 行坐标 y，向下递增，原点 `(0, 0)` 在左上角 |

地图是从斜上方看下去的（地面向后倾，接近 2.5D 等距视角），所以格子呈扁的四边形；机器人、禁止通行牌都是立在地面上的「立牌」，会挡住背后一格的一部分，这是这套视角的正常表现，不影响判定——能不能走只看格子的类型。

右上角的圆点徽标是连接状态：绿色「服务在线」表示刚才的请求成功了；红色「未连接服务」表示连不上后端。

控制面板里的三个数字：**位置**是 `(x, y)`，**朝向**是机器人当前面朝的方向，**状态**由后端给出（待命 / 移动中）。下面一条是本次会话的统计：**步数**是成功移动的格数，**经过**是走过的不同格子数（含当前格）。

图例在地图下方，颜色之外还有文字，投影或黑白打印也能分辨。

## 二、怎么操作

1. 在浏览器打开 `http://localhost:8080/`（后端已启动的情况下），先在开场弹窗里选**地图**（标准巡检区 8×8 / 仓储通道 10×8）和**机器人**，点「开始巡检」。切换地图时机器人会回到该图起点，步数与巡检痕迹一起清空。选过的组合会被记住，下次进来直接沿用；想重选就点左上角的 **◆ 场景**。
2. 右栏上方有两个模式：**自由移动**（默认）和**格点移动**。控制面板右边的副标题会跟着变：自由模式是「点地图走过去」，格点模式是「每次点击移动一格」。
3. **自由移动**：在地图上**按住**就出发，松手就到（也可以按住不放一路拖，机器人会跟着指针换目标，拖过哪格就走哪格）。点格子中间就站到格子中间，点靠边的位置就停在靠边的地方，不必落在格心。也可以按住 `W` `A` `S` `D` 或方向键连续走，松手就停。
4. **格点移动**：点右边的 **W / A / S / D** 按钮（箭头是朝向提示），每次走一格；也可以用键盘 `W` `A` `S` `D` 或方向键，效果一样。用 `Tab` 可以依次聚焦到按钮，回车或空格触发。
5. 点 **重新读取状态** 会重新向后端要一次完整状态，界面以后端返回的为准；同时会**清空本轮的巡检痕迹**（步数和「经过」归零，蓝色格子重新从机器人脚下那格开始算）。
6. **自动巡检**：点右栏的「自动巡检」，机器人会自己按蛇形路线把整张地图走一遍，面板上显示「巡检中 3/15」。巡检途中**点地图、按方向键或 WASD、切换模式**都会立刻接管并停止巡检；走完后提示「巡检完成：15 个点位，用时 xx 秒，移动 xx 步，新覆盖 xx 格」，同时出现「导出巡检报告」按钮，点一下就把本轮统计存成 Markdown 文件，同时往服务端存一条记录（提示里会写「并存档为第 N 条记录」）。自动巡检只在自由移动模式下工作。
7. 请求发出到返回之间，四个方向按钮和「重新读取状态」会变灰不可点，避免连点造成重复指令。

## 三、用摇杆走

控制面板上有一个 `用网页摇杆移动` 的开关：

- 打开后方向按钮会收起来，换成一个圆盘摇杆。按住圆盘往哪个方向拖，机器人就往哪个方向走；拖得越远走得越快，方向由拖的角度决定。
- 松手立刻停下，不用点任何按钮。
- 摇杆开着的时候键盘的 `WASD` 会暂停用；把开关关掉，方向按钮回来，键盘也跟着回来。
- 格点模式下摇杆也能用：推一下走一格，有 0.42 秒冷却，不会一口气冲出去好几格。
- 开关状态会被记住，下次打开还是上次的选择。

## 四、移动规则

### 自由移动（页面内仿真）

- 想去哪就点哪：目标点落在格子里的任何位置都行，机器人会走过去停在那个位置。
- 机器人是个半径为 0.26 格的圆，障碍格是正方形：贴着障碍走会**自动滑开**，不会卡住；被挡住时会沿边蹭过去。
- 点在地图外的位置、或者点在禁止通行牌上，机器人不会动，右侧会提示「那一格立着『禁止通行』牌，站不了人」。
- 目标点和机器人之间隔着障碍时，会自动绕路（走格子的上下左右，不会斜穿）；按住不放改方向、或者连着快速点目标，都会从当前位置重算，不会抄近路穿过牌子。
- 自由移动**只在这个页面里生效**，不会写回后端；切回格点模式会重新读一次后端状态，机器人会瞬移回服务端记录的位置——这是设计上的取舍，不是 bug。

### 格点移动（与后端同步）

- 一次只能走一格，只能走上下左右，没有斜走。
- 撞到障碍物会被拒绝，机器人停在原地。
- 走出 `0–7` 的边界会被拒绝，机器人停在原地。
- 移动成功后，朝向会变成移动的方向。
- 页面**不预测**位置：格子里的机器人画在哪里，完全取决于后端返回的坐标。

### 两种模式共同的部分

- 走过的格子会留淡蓝底色和小圆点，方便演示时看出路线；机器人有 260ms 的滑动动画，系统开了「减少动效」时自动关闭。
- 轨迹只记在当前页面里：刷新页面、或在别处（比如另一个标签页）把机器人移走后再点「重新读取状态」，如果位置跳变超过一格，轨迹会自动清空重来——宁可重算，也不画错的路线。

## 五、失败了会看到什么

| 现象 | 提示 | 处理 |
| --- | --- | --- |
| 撞障碍 / 越界 | 「移动被拒绝：已到地图边界，无法继续移动」等，橙色提示 | 换个方向走；位置没有变化 |
| 自由模式下点到禁止通行牌 | 「那一格立着『禁止通行』牌，站不了人。」，橙色提示 | 点旁边空地；机器人在原地没动 |
| 请求超时（8 秒）、断网、后端 5xx | 「移动结果未确认：…请点『重新读取状态』」，红色提示 | 先点「重新读取状态」确认实际位置，不要连续点方向键 |
| 打开页面就连不上后端 | 地图区显示「地图加载失败：…请启动后端后点『重新读取状态』」，方向按钮不可用 | 启动后端（见 [backend/README.md](../backend/README.md)），再点「重新读取状态」 |
| 接口返回的 JSON 结构不对 | 「服务返回的状态格式不正确：…」 | 属于后端问题，把提示和响应贴给 C 排查 |

失败时画面上保留的是**上一次确认过的状态**，不会把机器人的位置改到「假想」的位置。

## 六、关于「共享状态」

机器人状态只有一份，保存在后端内存里，所有打开页面的人看到的是同一台机器人：

- 别人移动了，你这边不会自动刷新；点一次「重新读取状态」就能对上。
- 刷新页面会重新拉一次状态，位置不会丢。
- 重启后端会回到初始位置 `(0, 0)`、朝向 `up`、只有固定的三个障碍物。

## 七、常见问题

- **页面空白 / 只有文字**：多半是后端没启动（页面是后端托管的），先确认 `python -m uvicorn app.main:app --reload` 在跑。
- **按钮一直是灰的**：说明还没成功拿到状态，看地图区或右上角徽标的提示。
- **刷新后位置变了**：正常，说明期间有人（或你自己）移动过，以后端当前状态为准。
