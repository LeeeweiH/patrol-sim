# 使用指南（前端）

面向第一次打开页面的同学：怎么看图、怎么操作、出错怎么办。技术细节和接口契约见 [03_项目架构与接口.md](./03_项目架构与接口.md)。

## 一、界面上都有什么

页面分左右两块：左边是地图，右边是控制面板和状态。

| 标记 | 含义 |
| --- | --- |
| 浅色空格子 | 可通行区域 |
| 深色斜纹格 + 「障」 | 障碍物，不能进入 |
| 橙色格 + 「机」 + 箭头 | 机器人当前位置，箭头是当前朝向（↑↓←→） |
| 最上面一行的 0–7 | 列坐标 x，向右递增 |
| 最左一列的 0–7 | 行坐标 y，向下递增，原点 `(0, 0)` 在左上角 |

右上角的圆点徽标是连接状态：绿色「服务在线」表示刚才的请求成功了；红色「未连接服务」表示连不上后端。

控制面板里的三个数字：**位置**是 `(x, y)`，**朝向**是机器人当前面朝的方向，**状态**由后端给出（待命 / 移动中）。

图例在地图下方，颜色之外还有文字，投影或黑白打印也能分辨。

## 二、怎么操作

1. 在浏览器打开 `http://localhost:8080/`（后端已启动的情况下）。
2. 点右边的 **↑ ↓ ← →** 按钮，每次移动一格。
3. 也可以用键盘的方向键，效果一样；用 `Tab` 可以依次聚焦到按钮，回车或空格触发。
4. 点 **重新读取状态** 会重新向后端要一次完整状态，界面以后端返回的为准。
5. 请求发出到返回之间，四个方向按钮和「重新读取状态」会变灰不可点，避免连点造成重复指令。

## 三、移动规则

- 一次只能走一格，只能走上下左右，没有斜走。
- 撞到障碍物会被拒绝，机器人停在原地。
- 走出 `0–7` 的边界会被拒绝，机器人停在原地。
- 移动成功后，朝向会变成移动的方向。
- 页面**不预测**位置：格子里的机器人画在哪里，完全取决于后端返回的坐标。

## 四、失败了会看到什么

| 现象 | 提示 | 处理 |
| --- | --- | --- |
| 撞障碍 / 越界 | 「移动被拒绝：已到地图边界，无法继续移动」等，橙色提示 | 换个方向走；位置没有变化 |
| 请求超时（8 秒）、断网、后端 5xx | 「移动结果未确认：…请点『重新读取状态』」，红色提示 | 先点「重新读取状态」确认实际位置，不要连续点方向键 |
| 打开页面就连不上后端 | 地图区显示「地图加载失败：…请启动后端后点『重新读取状态』」，方向按钮不可用 | 启动后端（见 [backend/README.md](../backend/README.md)），再点「重新读取状态」 |
| 接口返回的 JSON 结构不对 | 「服务返回的状态格式不正确：…」 | 属于后端问题，把提示和响应贴给 C 排查 |

失败时画面上保留的是**上一次确认过的状态**，不会把机器人的位置改到「假想」的位置。

## 五、关于「共享状态」

机器人状态只有一份，保存在后端内存里，所有打开页面的人看到的是同一台机器人：

- 别人移动了，你这边不会自动刷新；点一次「重新读取状态」就能对上。
- 刷新页面会重新拉一次状态，位置不会丢。
- 重启后端会回到初始位置 `(0, 0)`、朝向 `up`、只有固定的三个障碍物。

## 六、常见问题

- **页面空白 / 只有文字**：多半是后端没启动（页面是后端托管的），先确认 `python -m uvicorn app.main:app --reload` 在跑。
- **按钮一直是灰的**：说明还没成功拿到状态，看地图区或右上角徽标的提示。
- **刷新后位置变了**：正常，说明期间有人（或你自己）移动过，以后端当前状态为准。
